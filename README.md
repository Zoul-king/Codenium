# Codenium

Sitio marketing construido con Next.js 15 para presentar servicios, planes, portafolio y contacto.

## Estructura

```text
src/
  app/                # Rutas App Router
  components/ui/      # Iconos y piezas UI reutilizables
  features/site/      # Dominio del sitio marketing
  hooks/              # Hooks compartidos
public/               # Assets estáticos
scripts/              # Scripts de desarrollo
```

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run start
```
